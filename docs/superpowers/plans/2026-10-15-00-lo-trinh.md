# Tin Video Studio — Lộ trình triển khai

Đặc tả: `docs/superpowers/specs/2026-10-15-tin-video-studio-design.md`

Dự án chia 4 chặng. Mỗi chặng ra phần mềm chạy được và test được. **Xong chặng nào, Hải duyệt rồi mới viết kế hoạch chi tiết cho chặng sau** (quy tắc cửa kiểm mỗi bước). Kế hoạch chặng sau viết dựa trên code thật của chặng trước, không đoán trước.

| Chặng | Kết quả | File kế hoạch |
|---|---|---|
| 1. Nền móng + model + server | App Next.js chạy được, đăng nhập 5 tài khoản, các lớp model nghiệp vụ, 3 API (danh sách giọng, tạo giọng, tìm cảnh trám) với Google TTS / Pexels / Pixabay và bản giả lập | `2026-10-15-01-chang-1-nen-mong.md` |
| 2. Bộ dựng video | Lớp phong cách trừu tượng + phong cách Theanh28, trộn âm, vẽ khung, mã hoá WebCodecs + mux MP4 (mediabunny 1.61.x) trong worker. Trang `/dev/dung-thu` dựng tin Phú Thọ từ dữ liệu cố định ra MP4 | `2026-10-15-02-chang-2-bo-dung.md` |
| 3A. Bộ dựng bền hơn | Nhả bộ giải mã theo cảnh, nền mờ thu nhỏ thay blur mỗi khung, bộ giới hạn đỉnh có nhìn trước, probe worker, cắt lặng giọng, dòng nguồn tin không đè logo; đo lại tốc độ dựng (mục tiêu ≤ 1,5× thời lượng) | `2026-10-15-03a-chang-3a-bo-dung-ben-hon.md` |
| 3B. Lớp dữ liệu và dịch vụ trình duyệt | Snapshot/restore domain, IndexedDB (bản nháp, thương hiệu, file tải lên), đoán từ khoá Việt → Anh + từ điển, client tìm cảnh trám, kho nhạc, kiểm file tải lên, ảnh giả PNG thật, container dịch vụ | `2026-10-15-03b-chang-3b-lop-du-lieu.md` |
| 3C. Trình 5 bước | WizardController + controller và view từng bước (nhập tin, giọng, duyệt cảnh trám, nhạc, dựng), lưu/mở lại bản nháp, bộ thương hiệu. **Đã xong, chạy thật 2026-10-15** (đặc tả mục 12) | `2026-10-15-03c-chang-3c-trinh-5-buoc.md` |
| 4. Nghiệm thu + deploy | Test toàn luồng Playwright, so khung với video mẫu, đo mức âm, deploy Vercel, hướng dẫn Hải thêm biến môi trường | viết sau khi Hải duyệt/merge 3C |

Phụ thuộc giữa chặng: 2 dùng model của 1. 3A sửa bộ dựng của 2 (độc lập với 3B). 3B dùng model của 1 và dịch vụ của 1–2. 3C dùng 3A và 3B. 4 dùng tất cả. Chặng 3 được tách làm 3 phần vì gom ba nhóm việc độc lập; mỗi phần ra phần mềm chạy được và test được.
